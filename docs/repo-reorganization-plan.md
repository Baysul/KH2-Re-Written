## Principles

- Game data, manifests, selections, captures and saves stay outside the checkout (AGENTS.md). Anything in `.local/` is ignored and is only for development outputs.
- Keep paths AGENTS.md names: `docs/fidelity-contract.md`, `docs/milestones.md`, `docs/unknowns.md`, `docs/tasks/`.
- Move a folder only when every reference to it is updated in the same commit. Docs cite files by path, so a move is a link sweep.
- No new crate or folder until code needs it.

## Phases and gates

Each phase is a separate commit and passes `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`, `cargo test --workspace --locked`, `cargo build --workspace --locked`, and `cargo run -p windows_shell --locked -- --frames 180` (for phases that touch code).

- **Phase 0 (this change, no moves).** Add `ARCHITECTURE.md`, this plan, and the `.gitignore` allowlist line for `ARCHITECTURE.md`. Commit and push. No files are moved or deleted.
- **Phase 1 (after approval; no tracked code touched).** D1, M10, D5, D6 (after confirming each clone is not needed), M1, M2, M3, M4. Local file moves and deletions only. Pre-move checks: the playable test room and title threads have no running session that reads `.local/test-room/`.
- **Phase 2 (after approval).** M5 and D7. Docs only. Verify that no link points at an old path (`git grep -n 'docs/<old-name>'`) and that `docs/tasks/*` still resolves.
- **Phase 3 (after the title and playable-room threads push).** M6, M7 (if approved), and the gap G5 decision on `glurbus-splash.png`. Code moves. Run the full check list.
- **Phase 4 (only when a tested behavior needs it).** M8. Creates `crates/game_core`. Not scaffolded before then (AGENTS.md).

## Gaps this plan does not fix (listed for decision)

- **G1: Private data in `.local/`.** Covered by M1.
- **G2: Unrelated game clones.** Covered by D5, D6.
- **G3: `.local/tools/` is a research workspace.** After M2 and M3 it would hold only what cannot move; consider removing the folder.
- **G4: `.gitignore` allowlist.** Adding `ARCHITECTURE.md` is part of phase 0. Each new allowlist entry needs a provenance review (AGENTS.md).
- **G5: `glurbus-splash.png` is git-ignored** but `splash.rs` loads it. A clean clone cannot show the splash. Options: add `!/crates/windows_shell/assets/glurbus-splash.png` to `.gitignore` after confirming the image's provenance and that the owner wants it tracked (AGENTS.md requires a provenance review for allowlist entries), or load it from a private path. The title thread should decide. Blocks D4.
- **G6: Test room and title modules.** `windows_shell` holds both presentation and game-state code. Phase 4 addresses this; no earlier action.
