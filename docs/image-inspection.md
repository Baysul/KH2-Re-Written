# Quarantined image research

`image_inspector` loads selected replacement textures directly from read-only KH2 package handles after a fresh complete source rehash. It is a research viewer, with no gameplay qualification or simulation. All input manifests/selections and output logs/captures belong in private external storage; never put source-derived artifacts in the checkout.

Build with `cargo build -p windows_shell --bin image_inspector --locked`. Invoke the binary with four arguments: selected Steam installation, bound private manifest, explicit private image selection, and a new private JSONL log. Selection uses the original probe's source-bound schema, `inspect_hd_images: true`, and the explicitly chosen DDS CPU profile. Optional `--capture-dir` names an existing private directory; `--tour` captures all six views of each actual image; `--frames N` sets a safety limit (180–100000). Existing files are refused.

Controls: left/right change images; C composite; V stored RGB; R/G/B/A isolate channels; F fit; 1 native size; plus/minus zoom; Escape close. Tour mode preserves its state until each asynchronous capture completes and ignores view-changing keys. The window title carries the selected image/mode/dimensions and quarantine status. Native tall images can exceed the viewport; fit/zoom controls are for inspection, not installed UV or display calibration.

`Verify-InspectorCaptures.ps1` binds tour records to a previously independently verified source pixel corpus, uses WIC to decode each captured PNG, checks readback hashes and compares the native visible source region exactly. It refuses incomplete tours, duplicate states, unknown projections, non-native scale, unsafe filenames and ambiguous source identities. T026's proof covers 19 images/six modes/81,469,440 visible pixels. It does not qualify fit/zoom, physical input, installed shaders/fonts, complete atlases, geometry or animation. See [T026](tasks/T026-source-image-inspector.md).
