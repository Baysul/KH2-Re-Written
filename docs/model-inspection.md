# Model structure inspection

The existing `original_probe` accepts `inspect_model_skeletons: true` in a schema-1 explicit private selection bound to the selected source identity, index, ordinal and name hash. It freshly rehashes the complete candidate before model reads; quarantine remains in force. Output is new private metadata. No source writer, asset-file export or game session is involved. Omitted opt-in preserves ordinary probe fields/behavior.

`mdlx_legacy_3_4_structure_v1` reads type-4 BAR payloads with a type-3 root at reserved offset `0x90` and forward relative links to type-3/type-4 blocks. Limits are 32 MiB per payload, 16 blocks, 2,048 declared bones and 4,096 groups per block; ordinary selection/aggregate/report limits also apply. It retains all eight header words, both halves of the packed count word, eight words per group, and a fingerprint of the legacy reader's fixed 288-byte unknown region. A zero bone pointer yields no records even when the header declares bones.

Each 64-byte bone retains four signed 32-bit header words, eight signed 16-bit views of those same bytes, and twelve raw float-bit words. Pinned `Mdlx.Model.cs` and `Models/ModelCommon.cs` disagree on bone header fields and model type labels. Neither interpretation becomes authoritative simulation data. Legacy index/parent observations report roots, missing parents, duplicate indices, ordering and chains reaching a cycle. Duplicate indices make cycle accounting ambiguous (`null`); records stay intact. Rust chain accounting is linear in the bounded bone count.

`tools/Verify-ModelSkeleton.ps1` independently reconstructs selected originals and every replacement with the existing pinned transform/.NET deflate oracle, reads all BAR scalars, and compares model fields using an owned BinaryReader adapter guided by the pinned public layout. It records new private evidence and rejects discrepancies. Full OpenKH model reading, VIF/DMA decoding, mesh assembly, transform multiplication, bind poses, animation and installed rendering do not execute in this route.

T029 qualifies finite structural observations over three selected models. Mesh and motion decoding, additional format profiles, semantic identity and a model viewer remain required. Names are candidate selectors; they do not prove character identity or installed behavior. Source stability and raw field agreement do not establish supported gameplay input or whole-game equivalence.
