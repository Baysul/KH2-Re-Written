No game content is used in the smoke app. Existing Apache-2.0 repository license retained. Bevy 0.19.1 is MIT OR Apache-2.0. serde/serde_json, sha2 and flate2 1.1.10 are pinned through Cargo.lock. No original game executable code is copied.

The resolved Windows dependency metadata is in `dependency-inventory.csv` (269 packages when generated). flate2 uses its Rust backend (miniz_oxide), with no new native toolchain requirement. SPDX labels are metadata evidence, not the final license-text/attribution audit; release packaging still needs all applicable license texts and notices. No font or code from Skate3/iw4L is copied. The PowerShell comparison script compiles the audited, unchanged OpenKH transform privately in memory and does not invoke source-writing tools. See the pinned tool audit for distinct license dispositions.

No release package exists. Finite storage decoding samples and a running reference title do not establish whole-game compatibility, full license audit, fresh-machine verification or fidelity.
